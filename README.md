# 📱 Projeto Operadoras
Um sistema completo para gerenciamento e análise de operadoras de telefonia.

🚀 Sobre o Projeto
Sistema desenvolvido para facilitar o gerenciamento de informações sobre operadoras de telefonia, oferecendo uma interface moderna e intuitiva para cadastro, consulta e análise de dados.

✨ Funcionalidades
📊 Dashboard - Visão geral das operadoras

👥 Cadastro de Operadoras - Adicione novas operadoras

🔍 Consulta Avançada - Busque operadoras por diversos critérios

📈 Análise de Dados - Relatórios e estatísticas

⚡ Interface Responsiva - Funciona em qualquer dispositivo

🎨 Design Moderno - Interface clean e intuitiva

🛠️ Tecnologias Utilizadas
Frontend: React, TypeScript, Tailwind CSS

Backend: Node.js, Express

Banco de Dados: MongoDB

Autenticação: JWT

🎮 Como Usar
Cadastrar Operadora
Acesse a página "Cadastrar Operadora"

Preencha os dados necessários:

Nome da operadora

Planos disponíveis

Cobertura

Clique em "Salvar"

Consultar Operadoras
Vá para a página "Consultar"

Use os filtros para refinar sua busca

Visualize os resultados em tempo real
